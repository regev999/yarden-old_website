# ירדן כרם – האתר החדש

אתר סטטי (HTML/CSS) שנבנה מכל התוכן של אתר הוורדפרס הקודם, בעיצוב חדש.
כל כתובת של האתר הישן נשמרה בדיוק כמו שהייתה, כך שקישורים ותוצאות בגוגל ממשיכים לעבוד.

## מבנה

| תיקייה | מה יש בה |
|---|---|
| `site/` | האתר המוכן להעלאה – זה מה שמעלים לאחסון |
| `build/build.py` | בונה את `site/` מתוך `data/content.json` |
| `build/extract.py` | מחלץ את התוכן מקובץ הייצוא של וורדפרס (`data/wordpress-export.xml`, לא נשמר בגיט כי יש בו פרטי מגיבים) |
| `build/assets/` | עיצוב (`style.css`), סקריפט (`main.js`), אייקון |
| `data/media-needed.txt` | רשימת התמונות שהאתר משתמש בהן |

## בנייה מחדש

```bash
python3 build/build.py            # אחרי שינוי בעיצוב/בקוד
python3 build/extract.py          # רק אם יש ייצוא וורדפרס חדש ב-data/
```

## מה עוד צריך

1. **תמונות** – להעתיק את תיקיית `wp-content/uploads` מהאחסון הישן אל `site/wp-content/uploads/`.
   עד אז התמונות פשוט מוסתרות והעמודים נראים תקין.
2. **טפסי יצירת קשר** – כרגע טופס פותח את תוכנת הדואר של הגולש. כדי לקבל פניות ישירות,
   לפתוח טופס ב-Formspree/Getform ולהדביק את הכתובת ב-`FORM_ENDPOINT` שב-`build/build.py`.
3. **אחסון** – אפשר להעלות את `site/` לכל אחסון סטטי (Netlify, Cloudflare Pages, GitHub Pages, או תיקיית public_html).
